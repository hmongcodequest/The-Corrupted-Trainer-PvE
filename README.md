## 🔧 How It Works

The tool reads and modifies values in the game process's memory using standard Windows API calls. It features:

- **In-memory modifications** — reads and modifies values in real-time
- **No external dependencies** — runs entirely as a standalone .exe
- **Persistent toggles** — features stay active until turned off
- **Hook self-healing** — re-applies patches the game tries to roll back

All modifications disappear when you close the tool. Your game files remain untouched.
